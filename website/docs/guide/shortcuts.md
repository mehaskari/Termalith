# Keyboard shortcuts

On Windows and Linux Termalith uses <kbd>Ctrl</kbd>+<kbd>Shift</kbd> where
macOS uses <kbd>Cmd</kbd>, so programs in the terminal keep their
<kbd>Ctrl</kbd> keys (<kbd>Ctrl</kbd>+<kbd>C</kbd> still interrupts).

| Action | macOS | Windows / Linux |
|---|---|---|
| Command palette | <kbd>Cmd</kbd>+<kbd>K</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>K</kbd> |
| New local terminal | <kbd>Cmd</kbd>+<kbd>T</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> |
| Close tab | <kbd>Cmd</kbd>+<kbd>W</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> |
| Next / previous tab | <kbd>Ctrl</kbd>+<kbd>Tab</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | same |
| Go to tab 1–9 | <kbd>Cmd</kbd>+<kbd>1</kbd>…<kbd>9</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd>…<kbd>9</kbd> |
| Find in terminal | <kbd>Cmd</kbd>+<kbd>F</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> |
| Copy / paste | <kbd>Cmd</kbd>+<kbd>C</kbd> / <kbd>V</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> / <kbd>V</kbd> |
| Font size bigger / smaller / reset | <kbd>Cmd</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> |
| Save a file in the editor | <kbd>Cmd</kbd>+<kbd>S</kbd> | <kbd>Ctrl</kbd>+<kbd>S</kbd> |

## Keyboard-only use

**Session list:** <kbd>↑</kbd> <kbd>↓</kbd> move between rows,
<kbd>→</kbd> opens a folder (or steps into it), <kbd>←</kbd> closes it (or
goes to the folder above), <kbd>Home</kbd> / <kbd>End</kbd> jump to the first
or last row, <kbd>Enter</kbd> connects, and <kbd>Shift</kbd>+<kbd>F10</kbd>
(or the context-menu key) opens the row's actions, where the arrow keys and
<kbd>Esc</kbd> work. Rows have descriptive labels for screen readers.

**Tab bar:** <kbd>←</kbd> <kbd>→</kbd> switch tabs, <kbd>Enter</kbd> moves
into the tab (the terminal or file list), <kbd>Delete</kbd> closes it,
<kbd>F2</kbd> renames it and <kbd>Shift</kbd>+<kbd>F10</kbd> opens its menu.

**Files panel:** <kbd>↑</kbd> <kbd>↓</kbd> move between files;
<kbd>Alt</kbd>+<kbd>↑</kbd> or <kbd>Backspace</kbd> opens the parent folder.
