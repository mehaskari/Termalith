# Termalith

**One workspace. Every connection.** An open-source remote administration
workstation: SSH terminals, SFTP, remote desktop, tunnels, serial and Telnet
consoles and network tools in one app, for macOS, Windows and Linux.

- **[User Guide](guide/index.md)**: installing, sessions, SSH, files, remote
  desktop, tools, shortcuts and troubleshooting.
- **[Security](security.md)**: how credentials, host keys and connections
  are handled, and how to report a problem.
- **[Changelog](changelog.md)**: what changed in each release.
