What it does

The everyday toolbox of an admin, in one app

Saved sessions on the left, tabs on the right — and every kind of connection you reach for during a working day.

Terminals

Work in many places at once

  • Local shells, tabs, up to 2×2 split panes
  • Broadcast typing with a loud banner
  • Snippets with {{variables}}, macros
  • Session logs, keyword colors, per-session look
  • Command palette ⌘K
SSH

Connect safely, stay connected

  • Password, keys, agent, one-time codes
  • Strict host keys, keychain secrets
  • Jump hosts, SOCKS/HTTP proxy
  • Tunnels -L -R -D, Mosh
  • X11 & agent forwarding, server monitor
Files

Move and edit files

  • SFTP panel or file-browser tab
  • FTP and FTPS (pinned certificate)
  • Drag and drop, queue with retry
  • Files follow the terminal's folder
  • Edit remote files with conflict check
  • SSH key manager
Everything else

Desktops, devices, diagnostics

  • RDP and VNC in a tab, or your own client
  • Serial consoles and Telnet
  • Ping, traceroute, port scan, DNS
  • Subnet calculator, Wake-on-LAN
  • Import from ~/.ssh/config & MobaXterm
Why Termalith

Free, cross-platform, careful by default

Most all-in-one admin tools run on one system or keep everyday features behind a paid edition. Termalith is MIT-licensed, the same on all three systems, and holds the keys to your infrastructure with care.

Secrets stay in the keychain

Passwords and passphrases live only in the system credential store, saved only after a login worked, never in logs or on command lines.

No silent trust

Unknown host keys are shown; changed keys are refused. Tunnels listen on loopback, forwarding is opt-in, unexpected server channels are rejected.

Native on three systems

A small Rust core with a web UI (Tauri), the same features on macOS, Windows and Linux, Intel and ARM, tested in CI on all six builds.

Free for any use

MIT licensed, no paid edition, no account, no session limits. Use it at home or at work, read the code, change it.

Nothing phones home

No telemetry. Crash reports stay on your machine. The update check runs only when you ask, or at startup if you turn it on.

Master password & portable

Optionally seal saved passwords with a master password, or run from a USB stick with all data in a folder next to the app.

Then install it

  1. Open the .dmg and drag Termalith to Applications.
  2. Open it. macOS refuses the first time because the app is not signed with a paid Apple certificate yet.
  3. System Settings → Privacy & Security → Open Anyway (macOS 14 and older: right-click the app → Open).
  4. Allow local network access when asked, to reach machines on your network.
  1. Run the -setup.exe (or the .msi for managed deployment).
  2. If SmartScreen warns, click More info → Run anyway (the installer is not signed with a paid certificate yet).
  3. Start Termalith from the Start menu.
# Ubuntu / Debian / Mint sudo apt install ./Termalith_*_amd64.deb # any distribution chmod +x Termalith_*_amd64.AppImage ./Termalith_*_amd64.AppImage

Questions

Short answers

Is it really free?

Yes: MIT licensed, free for personal and commercial use, no paid tier.

Which systems?

macOS 11+ (Apple Silicon, Intel), Windows 10/11 (x64, ARM64), Linux (x64, ARM64; AppImage and deb).

Is it a MobaXterm alternative?

For daily SSH, files, RDP/VNC and tunnels, yes, on all three systems; it imports MobaXterm sessions. A built-in X server on Windows is not there yet.

Where do passwords go?

Into the system keychain, only after a login worked, optionally sealed with a master password. Never into exports or logs.

Why the security warning?

The installers are not code-signed with a paid certificate yet. Check the download against SHA256SUMS.txt, or build from source.

How can I help?

Star the project, report problems and ideas in Issues, or send a pull request.
